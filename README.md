# 集贤科技端侧语音售前培训文档

这是 GitHub Pages 部署目录。

## 文件说明

- `index.html`：培训文档首页，已内嵌图片，可直接作为单页网页发布。
- `.nojekyll`：避免 GitHub Pages 使用 Jekyll 处理静态文件。

## GitHub Pages 发布信息

- 仓库：`haywardlin/uascent-training-materials`
- Pages 地址：`https://haywardlin.github.io/uascent-training-materials/`
- Source：`main` 分支根目录

## 后续更新

每次更新培训文档后，将新的 HTML 覆盖为 `index.html`，然后提交并推送到 `main` 分支即可。
